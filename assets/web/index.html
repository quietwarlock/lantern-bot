                  Startup

                  "Start Lantern when I sign in to Windows" and "Install to a permanent folder" are Windows-only. In Docker the container's restart policy starts Lantern with the server.
                  Changes apply to the next command. A new token is used after Stop bot, then Start.

                  Set up Lantern

                  1. Open the Discord Developer Portal, press New Application, and give it a name. On the Bot page, turn on Message Content Intent. Leave Presence and Server Members off.
                  2. On the Bot page press Reset Token and copy it. Paste it in Bot token above.
                  3. Save, then use the invite link to add Lantern to your server.
                  4. Your Discord user ID (Owner ID) gives you full control: Discord Settings > Advanced > Developer Mode, then right-click your name > Copy User ID.
                  5. Save settings and press Start. The log shows "Online as …" when it works, or says what to fix.
